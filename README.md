# busnavi — 広島駅南口バス案内

広島駅南口から紙屋町・八丁堀へ向かうバスの発車時刻と乗り場を案内します。

公開サイト：https://reigreen016.github.io/busnavi/

## 表示

- 左側に乗り場図、右側に発車案内を同じ幅・高さで表示。色分けの凡例は見出しの右端に表示します。
- 紙屋町を青、八丁堀をオレンジで交互に強調。発車まで3分以内の行は同じ1.5秒間隔で明暗を切り替えます。
- 直近便の乗り場は方面ごとに大きな番号を横1列で表示します。図は各方面の次の便から3分以内の乗り場を強調します。発車案内内の乗り場番号は白い四角で表示します。図の「紙／八」は非点灯側も淡い色で表示します。23・20・17番は番号の左側に表示します。
- 遅延便は元の予定時刻を小さな取り消し線付きで表示し、補正後の発車時刻を赤字で表示。補正後の時刻で並べ替えます。
- リアルタイム情報で予定どおりと確認できた便は「定刻」を緑字、情報がない便は「予定」と表示。
- 日時設定、接続状態、各社の更新時刻・GTFS情報は最下部の「日時設定・データ」に格納。
- 日本語・英語・韓国語・簡体字・繁体字に対応。停留所・会社・行き先の翻訳はGTFSのtranslations.txtを使用し、未翻訳は原文を表示します。原図の文字は日本語です。

## ローカル起動

リポジトリのフォルダで実行します。

```sh
python3 -m http.server 8001 --bind 127.0.0.1
```

http://127.0.0.1:8001/ を開いてください。公開APIに接続します。

## 静的GTFS

4社のGTFS ZIPから `data/timetable.json` を生成しています。古い週末CSV・フォールバックJSは使用しません。

| 会社 | 収録期間 |
| --- | --- |
| 広島バス | 2026-10-09〜2027-04-09 |
| 広島電鉄 | 2026-10-27〜2027-04-27 |
| 広島交通 | 2026-10-10〜2027-04-10 |
| JRバス中国 | 2026-10-25〜2027-04-25 |

出発停留所は「広島駅」の完全一致で、乗車可能な便のみ対象です。広島駅新幹線口発は含みません。紙屋町・八丁堀が出発停留所より後のstop_sequenceにあり、降車可能な便を選びます。行き先文字列や系統番号だけでは判定しません。

calendar.txtとcalendar_dates.txtで運行日を判定し、前日運行の24時超の便にも対応します。乗り場はplatform_codeを使用し、空欄は推測しません。循環路線など時間のかかる便も含むため、各停留所の到着時刻を併記します。

GTFSの更新は手動です。ZIPを用意して次を実行し、生成物を公開してください。

```sh
python3 scripts/build_data.py /path/to/GTFSフォルダ
python3 scripts/verify_gtfs.py /path/to/GTFSフォルダ
```

## リアルタイム情報

API：https://busnavi-realtime.rnp9cf8k76.workers.dev/api/realtime

Cloudflare Durable Objectで4社のTrip Updates取得を一か所に集約します。各社への取得は最短30秒間隔で、同時アクセスをまとめます。閲覧者がいない間は取得しません。画面は30秒ごとに確認し、タブ非表示・指定日時モードでは停止します。

trip_id・運行日・停留所・停車順序を照合できた便のみ予測を反映します。配信元の更新から90秒を超えた情報は使用しません。取得できた運休・停車取りやめは案内から除きます。追加便の生成や未取得区間の遅延推測は行いません。下車停留所の発車予測を到着予測に読み替えません。

APIの反映手順は [worker/README.md](worker/README.md) を参照してください。GitHub Pagesの更新とAPIの更新は別操作です。

配信元：https://www.bus-kyo.or.jp/gtfs-open-data （CC0）

## 読み込みの軽量化

乗り場図は元PNG（6,224,310バイト）を高画質WebP（品質95、449,750バイト）に変換しています。初回のロスレスWebP版（3,402,750バイト）からさらに約87%削減しました。解像度は1824×2336のままで、文字・線の見やすさを拡大比較して確認しています。優先読み込みと非同期デコードを指定し、画像の読み込み前から寸法を確保しています。元PNGとロスレス版は参照用に残しています。

時刻表は案内対象の便に必要な運行カレンダー・例外日・翻訳だけを収録し、4,587,386バイトから1,286,933バイトに削減しました。全2,835件の便と該当する運行日を保持します。画像と時刻表の合計ファイルサイズは約84%減です（実際の通信量は配信時の圧縮・キャッシュにも依存します）。

横並びの番号は56pxのまま、入りきらない場合はその列だけ横スクロールできます。左右は同じ幅・高さのまま、右上に番号列、右下に発車案内を配置します。スマートフォンでは縦並びにし、図上の紙/八・K/Hラベルを小さくして密集を抑えています。
